# Mondo → ICD-11 synonym review

Expert review of synonyms proposed from the Mondo Disease Ontology for the ICD-11 Foundation.
Site: https://tannerzhang.github.io/foundation-synonym-enrichment/

This repository holds only the published review pages (built from release v20261030).
Reviewers are invited and sign in with ORCID; decisions are stored on the review server.
Credits for the pipeline team, data sources and tools are in the wiki.

Content: Mondo Disease Ontology (CC BY 4.0); ICD-11 Foundation © World Health Organization (CC BY-ND 3.0 IGO).
Proposed synonyms are under review and are not part of ICD-11.
